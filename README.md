# Agent Safety Atlas · frozen release

A static, frozen release of the Agent Safety Atlas. It does not update.

- **Universe, Paths, Explore**: the frozen field map v2 (frozen 24 October 2026): 5,378 works first published through
  30 September 2026, 14 themes and 61 consensus clusters.
- **Findings**: research evolution, foundations and protection, opportunities and tests, evidence and checks; each
  finding opens on its charts and the records behind them.
- **Papers**: the 5,782 works of the collection, including works first published after the field cutoff.
- **More**: method, data and versions (data release R071, labels A7.2).
- `tables/`: the CSV files linked from the pages.

Open `index.html` through any static web server.
